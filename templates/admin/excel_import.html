Import Câu Hỏi Hàng Loạt Từ Excel

Tải file template chuẩn, điền dữ liệu và tải lên để import vào cơ sở dữ liệu

Tải File Template Mẫu (.xlsx)
Hướng Dẫn Chuẩn Bị File Excel
  1. Bấm nút "Tải File Template Mẫu (.xlsx)" ở góc trên bên phải.
  2. Mở file bằng Microsoft Excel, Google Sheets hoặc LibreOffice.
  3. Giữ nguyên dòng tiêu đề (Dòng 1) gồm 9 cột chuẩn:
    • Cau_hoi: Nội dung câu hỏi (bắt buộc)
    • Lua_chon_1 đến 4: 4 phương án trả lời
    • Dap_an_dung (1-4): Số nguyên 1, 2, 3 hoặc 4
    • Giai_thich: Lời giải thích ngữ pháp
    • Level: Tên level (VD: Beginner, Elementary, Pre-intermediate, Intermediate, Advance) hoặc Rank order
    • Chu_de_id (tùy chọn): ID của chủ đề trong hệ thống (hoặc để trống nếu là câu hỏi dùng chung)
  4. Lưu file dưới định dạng .xlsx và upload ở khung bên phải.
